# Portfolio

## Requirements

Based on the concepts that you've learned in this section (components, props, states etc), create a portfolio website which should include the following details (in individual sections):

- Unique/small introduction about you
- Projects you've made till now
- Your skills and expertise
- Your education
- Your hobbies
- A form to reach out to you (should contain input for email, name, contact no and a text area section which says "how can i help") on form submission, you should receive a mail.
- Form should be validated properly (numbers should be of 10 digits, mail should be validated)
- Your social media handles including GitHub, LinkedIn etc

## Guidelines

- Create a separate repo
- Create branch as and when needed
- Commit your code daily, use atomic and meaningful commits
- Raise PRs on daily basis
- Do not merge before review
- Deploy this practical
- Share repo URL, link of raised PRs and deployed URL here.
